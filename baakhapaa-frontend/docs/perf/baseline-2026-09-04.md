# Bundle baseline — 2026-09-04, before code splitting

Recorded before any change, so the split that follows is a comparison rather
than a hope.

## Build output

    build/assets/index-*.js    476,817 bytes   (146.34 kB gzipped)
    build/assets/index-*.css    40,700 bytes   (  8.96 kB gzipped)
    build/index.html               870 bytes

**One JavaScript chunk.** `React.lazy` and dynamic `import()` appear zero times
in `src/`, so every route is in it.

## What that means per route

Every visitor downloads all fifteen pages before the first one renders:

| Route | What it needs | What it downloads |
|---|---|---|
| `/login` | a form | the editor, the storyboard viewer, the 19-lesson course, the pricing page |
| `/terms` | one markdown document | everything, plus the other document |
| `/dashboard` | a project list | the same everything |

The two legal documents are inlined into the bundle through the
`virtual:legal-documents` module — 14,198 bytes of markdown that only two routes
of fifteen ever read.

## Why this is the measurement that matters

146 kB gzipped is several seconds of blank screen on a 3G connection, which is
the connection this product is being built for. It is also the cheapest problem
in the codebase to fix: the routes are already separate files and nothing shares
mutable state across them.

## The target

Split per route. The shared chunk should hold React, the router, the auth and
language providers, the error boundary and the command palette — everything
rendered on every route — and nothing else.
