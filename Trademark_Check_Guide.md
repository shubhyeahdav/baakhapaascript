# Trademark Check Guide — For Your Future SaaS Name

You said you'll pick the name later, so here's the exact process to run
yourself once you have candidate names — takes about 20 minutes per name.

## Step 1 — Nepal Trademark Search (free, do this first)

1. Go to the Department of Industry (DOI) Nepal's trademark search portal,
   or visit the Office of Company Registrar (OCR) for company name
   availability at **ocr.gov.np**
2. Search your candidate name — check both exact match and close
   phonetic/spelling variants
3. Also check company name availability separately from trademark — you
   need both clear if you plan to register a company under the same name

## Step 2 — International Trademark Search (free)

Since you're pricing in USD for international users, check global
availability too:

- **WIPO Global Brand Database** (branddb.wipo.int) — searches trademark
  filings across 70+ countries in one place, free
- **USPTO TESS** (tmsearch.uspto.gov) — if you'll ever target US customers
  specifically
- **Google + "[name] trademark"** and **Google + "[name] app"** — quick
  sanity check for existing products using the name informally, even if
  not formally trademarked

## Step 3 — Domain and Social Handle Availability

A name with a clear trademark path is only useful if you can actually claim
it online:
- Check **.com** availability (Namecheap, GoDaddy, or similar)
- Check Instagram, X, LinkedIn, and YouTube handle availability for the
  same name
- If the .com is taken but the concept is available elsewhere, weigh
  whether a slightly modified name (addition of a word, different TLD) is
  worth it

## Step 4 — Red Flags to Rule a Name Out Immediately

- An identical or confusingly similar name already used by another
  screenwriting/production software company (Final Draft, Celtx,
  StudioBinder-adjacent names are risky even if not identical)
- A name matching an existing trademark in **Nepal Class 9 or Class 42**
  (software/SaaS trademark classes) — even if the product is different,
  a live registration in these exact classes is the highest risk
- Generic/descriptive words alone (e.g., "ScriptWriter") are hard to
  trademark and defend even if technically available

## Step 5 — When You Have 2-3 Candidate Names

Come back to this chat with them and I'll help you:
- Cross-check search results you find
- Weigh trademark risk vs. brand strength for each
- Draft the actual trademark application text if you decide to file one
  in Nepal

## Step 6 — Filing (once you've chosen)

If you want a registered trademark in Nepal (recommended once you have
real paying users), you'll file through the **Department of Industry**
with a local IP lawyer or trademark agent — DIY filing is possible but a
local agent (~NPR 15,000–40,000 typical range) avoids costly mistakes in
classification and reduces rejection risk.

---
*This is a self-check process, not a substitute for a formal legal
trademark clearance opinion. Once you've narrowed to a final name and have
real revenue at stake, get a proper clearance search done by an IP lawyer
before investing heavily in branding around it.*
